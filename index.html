📦 How to Install on Your Laptop

Choose whether you want AquaBuddy as a standalone desktop app or a Chrome browser extension:

💻 Desktop App (Mac & Windows)

Runs in your menu bar / system tray. The mascot walks across your desktop over all windows.

git clone https://github.com/RintuKT/AquaBuddy.git
cd AquaBuddy
npm install && npm start

🌐 Chrome / Edge Extension

Reminds you while browsing web pages.

  1. Clone or download repository ZIP from GitHub.
  2. Open chrome://extensions in your browser.
  3. Enable Developer mode (top right).
  4. Click Load unpacked and select the downloaded folder.
